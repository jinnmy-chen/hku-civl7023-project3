## 2. 直接运行

双击[启动PiPER.command](启动PiPER.command)，或从仓库根目录执行：

```bash
cd "05_Project3_月面机器人装配"
source .venv/bin/activate
python -u PiPER_Load_URDF/demo_load_urdf.py
```

VS Code使用`Python: Select Interpreter`选择`05_Project3_月面机器人装配/.venv/bin/python`。工作区默认路径已配置；如果编辑器之前记住过其他解释器，仍需切换。参考[VS Code环境说明](https://code.visualstudio.com/docs/python/environments)。

## 3. 在其他电脑配置

先选可用的兼容Python（本项目已验证3.12），在项目目录用`python3.12 -m venv .venv`创建环境并激活；Windows使用自己的Python路径及`.venv\Scripts\Activate.ps1`。然后安装[requirements.txt](</Users/yhdhhhh/Desktop/7023/05_Project3_月面机器人装配/requirements.txt>)。

```bash
python -m pip install -r requirements.txt
python -m pip check
python 验证环境.py
python PiPER_Load_URDF/demo_load_urdf.py
```

本Mac从PyPI取得的PyBullet 3.2.7需要源码编译；遇到`zutil.h`中`fdopen`与macOS头文件冲突时，激活虚拟环境后使用：

```bash
CPPFLAGS='-Dfdopen=fdopen' python -m pip install --no-build-isolation pybullet==3.2.7
```

此命令要求环境已装有`setuptools`、`wheel`等构建依赖，见依赖清单。不同系统不一定需要这个macOS兼容参数；先根据真实安装日志判断。安装来源与功能参考[PyBullet官方仓库](https://github.com/bulletphysics/bullet3#pybullet)、[PyPI](https://pypi.org/project/pybullet/)，冲突背景见[上游问题](https://github.com/bulletphysics/bullet3/issues/4607)。

Matplotlib及其依赖已在B第4步安装并记录版本；B的控制与阻尼求解使用NumPy，C新增装配模块使用SciPy。不要用`pip freeze`未经检查地覆盖可分享清单：本机曾从临时PyPI源码目录安装PyBullet，原始freeze包含临时目录引用，现已规范为`pybullet==3.2.7`，构建来源和修复参数另记在验证结果中。
