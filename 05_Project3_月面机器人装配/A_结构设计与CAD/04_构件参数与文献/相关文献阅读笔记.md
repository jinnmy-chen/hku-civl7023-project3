# A的相关文献与课程阅读笔记

1. Project 3正式Requirements，第1页：结构单元需交代几何、接口及装配顺序，并与六轴夹爪运动、仿真和三类评价衔接。本组六件数量为执行方案。
2. Design Automation讲义，PDF第2和8页：DfMA与连接简化。应用到本方案是重复单件、减少不同动作类别、统一接口与参数；可制造性仍需评估。
3. Bai讲义，PDF第11–14、20–36页：世界/构件/工具坐标与位姿。应用到交接的是底面原点、XYZ定义、工具朝向和质心偏移分开写明。
4. Shi讲义，PDF第6、10–12、18–26页：点位可行不保证路径可行；顺序、轨迹和已放件障碍需要明确。应用到本方案是先单件S2→L1_2，再下层到上层；本包名义点位表不是已验收路径。
5. Wang讲义，PDF第20–26页：使用本组机器人与TCP，闭环误差需要实际验证；不借用示例UR5参数或理想误差作为PiPER性能。
6. Ginés-Palomares等（2023），Scientific Reports，13，23053：烧结模拟月壤密度受材料及工艺影响，作为2500kg/m³均匀有效密度的候选参考；完整APA、DOI和适用限制见材料来源与假设.md。
