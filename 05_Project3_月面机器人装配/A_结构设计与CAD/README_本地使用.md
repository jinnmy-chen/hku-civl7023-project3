## 单位与候选参数

STEP、DWG及文件名含`mm`的STL按毫米；仿真使用米制STL／URDF。构件原点是底面中心，质心需要单独偏移；不得将mm直接作为m加载。

| 项目 | A已提供的候选值 | 当前已验收C运行使用值 |
|---|---:|---:|
| 单件质量 | 0.0726066666667kg | 0.070kg |
| 局部COM_Z | 0.010566253098889m | 0.011m |
| Ixx，kg·m² | 7.55471796165556×10⁻⁶ | 8.89583333333333×10⁻⁶ |
| Iyy，kg·m² | 1.87062546283222×10⁻⁵ | 1.82291666666667×10⁻⁵ |
| Izz，kg·m² | 2.040344×10⁻⁵ | 1.98333333333333×10⁻⁵ |

A采用2500kg/m³的文献参考均匀有效密度，非本组实测。独立实体比较确认外形与B槽榫V2一致，质量／惯量计算相符；**此次整理没有把候选值写入C装配控制或替换70g运行结果**。后续采用候选值时，须同时调整质量、COM、惯量和有关坐标换算，再验证抓放、释放、完整装配并补力矩评价。

当前70g装配的最新证据是[释放修复v4单次从零16/16结果](../运行验证/C_释放修复_2026-11-02/修复说明与验证.md)，最大构件误差0.8226mm／0.2878°。A包中的旧C历史数值没有另复制到这里，不能以0.3387mm的旧检查点续跑链替代最新运行，更不能标成A候选参数实验。

## 独立加载检查

在项目目录`05_Project3_月面机器人装配/`运行：

```bash
.venv/bin/python A_结构设计与CAD/06_可加载构件/运行加载检查.py
```

默认结果写入`运行验证/A_模型加载/日期时间/loading_result_LOCAL.json`，可用`--output`指定JSON路径。原加载逻辑不变，仅调整结果保存位置，避免写回模型资料目录。本次整合后实际加载通过：PyBullet3.2.7、34个碰撞子形状、0个关节，读回候选质量／COM／惯量正确；[结果](../运行验证/A_交付整合_2026-11-04/整合后模型加载结果.json)。加载检查不执行机器人抓放。
