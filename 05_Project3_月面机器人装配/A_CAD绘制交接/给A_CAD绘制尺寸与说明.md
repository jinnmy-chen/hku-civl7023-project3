## 3. CAD绘制顺序

1. 在XY基准面画中心位于O的50×30矩形，沿+Z拉伸22，得到主体。
2. 在两侧切除上述38×4×12槽。可先做一侧再关于XZ平面镜像；确认槽底Z=10、槽口开至主体顶面Z=22。
3. 在Z=22面画两个4×8矩形，中心分别为X=±20、Y=0；在Z=25平面画对应2×6矩形，直线放样并与主体合并。
4. 从底面做两个凹口：入口8×12在Z=0，放样切除至Z=0.5的6×10，再将6×10截面切至Z=3.5。注意切除方向朝实体内部+Z。
5. 检查布尔合并结果为**一个闭合实体**，没有多余薄片、开口面或互相分离的凸台。不要把六个构件合并为一个零件。
6. 建立两层装配：先画一个单件，再放置六个实例。保持各件局部轴与世界轴同向，不翻转第二层。
7. 按第6节导出CAD、STEP、网格、尺寸图与质量惯量。修改形状时另标版本，保留当前V2作对照。

SCAD源文件里的0.001、0.002、0.01等微小超切用于布尔运算，**不是额外的设计尺寸或制造公差**；参数化CAD采用本说明的名义尺寸。不要将凸台高3与凹口深3.5相加形成层距。

## 4. 接口间隙与装配关系

上层底面放在下层主体顶面Z=22。下层凸台进入上层凹口，名义最大插入3mm，上方还剩0.5mm空间。凹口内部6×10与凸台根部4×8相比较，X、Y方向各有每侧1mm间隙；入口8×12提供更大的导向开口。

这些值是**几何配合间隙**，尚不是加工公差、打印补偿或已验证的自动纠偏能力。当前方案没有压入卡扣或抗拔锁止，也没有三列之间的横向连接；A须评估连接方式、承载与稳定性。若增加连接件、底座、圆角或改槽，先给B、C新模型，再复查夹爪退出、可达性与碰撞。

## 6. A交回什么

| 交付内容 | 要求 |
|---|---|
| 参数化原生CAD | 保留主体、切槽、凸台、凹口特征与毫米单位；记录版本 |
| STEP实体 | 单件一个完整实体；装配文件中六件仍可分别识别，保留坐标系 |
| 米／毫米版STL | 明确文件名和单位；封闭、法线正确、保留实际凹槽与凹口 |
| 尺寸图 | 至少有俯视、正视、侧视，以及穿过一个凸台／凹口中心的剖视；标尺寸、原点、层距、间隙和版本 |
| 材料与质量属性 | 密度及出处／假设、单件质量、局部坐标系下质心、关于质心的完整惯量矩阵、轴定义与单位 |
| 装配与结构说明 | 六件定位、顺序、配合方式，连接与稳定性依据，未验证事项；如改形状写出差异 |

CAD体积核对值：**29042.6667mm³＝29.0426667cm³＝2.90426667×10⁻⁵m³**。这是当前理想V2实体的几何体积，不是质量；只适用于未加圆角或其他结构的同一形状。均匀材料可用质量m=密度ρ×体积V交叉核对。质心和惯量应从最终实体求取，不能把外包络中心(0,0,12.5)mm直接当质心，也不能用外包络实心长方体的惯量冒充实际形状。

模板使用SI单位：密度kg/m³、质量kg、质心m、惯量kg·m²；惯量需为**关于质心、表达在构件局部XYZ轴下**的矩阵，并说明CAD软件的惯性积符号约定。把几何原点平移到质心的操作交由C明确处理，不能悄悄改变STL的底面原点。

## 7. 与C联调前核对

- 单件包络50×30×25，主体高22；夹持面22，槽底Z=10，夹持槽向上敞开。
- 两凸台中心X=±20、Y=0；底部凹口同轴、深3.5含入口0.5；两层总高47。
- 单件闭合且连通，单位与原点正确；CAD、STEP、STL显示相同外形，体积与基线相符或有明确变更解释。
- 材料、质量、质心和惯量填写完整，有依据或标明暂定；不要把模板空值或任意测试值当作最终结论。
- 仿真碰撞要保留凹形：现有[34凸分块](../B_工作空间与设计约束/构件模型/convex)可作参考，不能把完整STL整体凸包化。它们当前作为零质量静态体加载；组织成动态刚体仍由C接入。

现有检查支持名义几何、可达抓放姿态与静态采样；实际摩擦夹持、带件轨迹、材料强度、释放落稳和关节力矩仍需后续验证。
