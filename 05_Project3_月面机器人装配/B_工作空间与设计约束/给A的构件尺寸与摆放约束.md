# 给A的构件尺寸、夹持与摆放约束（槽榫构件 V2）

更新：2026年10月29日。**本版替代此前纯长方体方案。** 模型版本：`P3-GrooveKey-v2`。这是本组设计基线，不是教师指定形状、尺寸或评分门槛。

**采用“两侧开放夹持槽＋上下定位凹凸接口”的构件。单件总包络仍为50×30×25毫米；主体高22毫米，顶部凸台高3毫米。六件搭成三列、两层，层距22毫米，总高度47毫米。** 新模型、夹指开闭、插合与取放几何检查已重做，旧版753状态的结论不用于本版。

## 1. 构件长什么样

![顶部凸台与开放夹持槽](../运行验证/工作空间/新构件_顶部与夹持槽.png)

两侧凹槽向上敞开，中间留下相对平行的夹持面；靠两端的主体部分保留完整宽度。顶部两块矮梯形凸台插入上一件底部对应凹口，先做松配合定位，不做压入卡扣或横向燕尾锁。

![底部定位凹口](../运行验证/工作空间/新构件_底部定位凹口.png)

![两层插合示意](../运行验证/工作空间/新构件_两层插合预览.png)

图为几何模型预览，不是实际抓放录像。定位凸台限制一定范围内的横向位移，但没有锁住上拔方向；这不是已经验证强度的结构连接。当前两层对缝布局仍需A论证连接与稳定性，必要时在基线内改进并重新检查。

## 2. A采用的具体尺寸

以下单位均为**毫米**。构件局部原点设在底面中心，X沿长边、Y沿宽边、Z向上。

| 特征 | 尺寸／范围 | 设计含义 |
|---|---|---|
| 总外包络 | X=−25～25，Y=−15～15，Z=0～25 | **50×30×25，包括顶部凸台** |
| 主体 | 高22 | 上一件底面落在此高度；不能用25作为层距 |
| 两个侧面夹持槽 | X=−19～19，Z=10～22；每侧向内切4 | 槽长38、高12，向上及对应侧面敞开 |
| 两个竖直夹持面 | Y=−11、+11 | 净夹持宽度**22**，抓取位于X=0 |
| 顶部定位凸台 | 两个，中心X=−20、+20，Y=0；Z=22～25 | 高3，底部4×8、顶部2×6；四侧为斜面 |
| 底部定位凹口 | 同样中心X=−20、+20，Y=0；深3.5 | 内部截面6×10，容纳下层凸台 |
| 凹口入口 | 底面开口8×12，0.5高后过渡至6×10 | 提供入口导向斜角 |
| 名义配合间隙 | 凸台根部至凹口每侧1；顶部至凹口顶0.5 | 是CAD几何间隙，不是制造公差或已验证的纠偏能力 |
| 两层层距／总高度 | **22／47** | 第二层底面Z=22，最高凸台顶Z=47 |
| 单件几何体积 | 约29.043 cm³ | 同材料下比原50×30×25实心长方体少约22.6%；未评价强度 |

夹持槽、底部凹口和顶部凸台已在封闭网格中真实建出，不是只画在表面的线条。**不要把整个凹形STL直接作为一个凸碰撞体载入**，否则槽和凹口会被填实。仿真应使用配套的34凸体分块加载器。

A可从[OpenSCAD可编辑CSG源文件](构件模型/groove_key_block.scad)或[毫米版STL](构件模型/groove_key_block_mm.stl)开始。CAD尺寸以本表、[参数记录](构件模型/parameters.json)及实际模型共同核对。修改尺寸／接口后须同步生成器和仿真几何，重新检查；当前SCAD源文件未在OpenSCAD应用中另行编译，已验证的STL由Python实体布尔运算生成。

## 3. 坐标、夹持点和夹爪开口

机器人基座固定在世界`(0,0,0)`，地面Z=0；构件局部轴与世界轴一致，构件姿态四元数`[0,0,0,1]`。工具朝下，四元数`[0,1,0,0]`，顺序xyzw；两指沿世界Y方向夹紧。

名义TCP沿用第2步约定：在`gripper_base`局部`[0,0,0.1358] m`，为两指关节原点的中点，非厂家标定接触中心。

| 项目 | 本版值 | 与旧版的区别 |
|---|---|---|
| 物体定位原点 | **底面中心** | 不再把外包络中心直接作为模型原点 |
| TCP相对构件底面原点 | **[0,0,14] mm** | 位于主体顶面22下方8；不是总顶面25下方8 |
| 接近／松开名义开口 | **36 mm** | 旧版50；本版参考姿态最近整体间隙约3.96 mm |
| 接近指面横向间隙 | 每侧约5.95 mm | 以22 mm宽夹持面和当前碰撞边距计算；最近距离可能出现在肩部 |
| 几何搬运开口 | **24.12 mm** | 旧版32.02；当前模型接近接触的名义开口约24.1 |
| 对非夹持面最近间隙 | 参考抓取姿态约2.95 mm | 肩部与夹指未发生非预期接触 |
| 搬运／上方接近TCP_Z | **82 mm** | 搬运时构件底面68，比完成结构顶面47高21 |

24.12 mm是静态几何搬运代理使用的开口，测得夹指与夹持面尚有约0.012 mm的数值间隙；**不能当作已经抓牢的控制目标**。真实夹紧力、电机目标、摩擦及接触停位留待抓放阶段验证。夹爪总名义行程仍是0–70 mm，不能把它当作任意外形的最大可抓宽度。本版验证22 mm宽夹持面，不为任意扩宽背书。

## 7. 实际完成的检查与结论

**本版1683个几何状态全部通过，六个取料位与六个装配位均找到合格关节解。** 每完成一件就移除对应取料障碍、加入已装构件，后续检查包含实际槽榫几何。

| 阶段 | 状态数 |
|---|---:|
| 张开接近 | 90 |
| 收拢夹爪 | 150 |
| 搬运代理抬起 | 90 |
| 水平搬运 | 228 |
| 最终下降／接口插合 | 693 |
| 张开松开 | 150 |
| 向上退回 | 78 |
| 空手返回下一个取料位 | 204 |
| **合计** | **1683** |

通常路径采样间距不超过5 mm，最终下降加密到0.5 mm；每次收拢和张开各检查25个开口。内部阈值：位置残差≤0.5 mm、朝向残差≤0.5°、各关节距限位≥2°、非接触几何间隙≥2 mm。采样最小关节余量约2.29°，最远取料位不宜外移。残差是IK／FK数值一致性，不能称为真实控制精度。

接口探针验证：正对插合，以及XY偏移(0.5,0)、(0,0.5)、(0.5,0.5)毫米时没有超出碰撞皮肤厚度的干涉；单轴偏移2毫米会出现干涉并被拒绝。**这只验证静态容纳空间，不证明斜面能自动纠正误差，也不保证任意±0.5 mm加旋转的综合公差。**

负向对照：同样50×30×25 mm的实心长方体在新抓取位置、24.12 mm开口下会与夹指重叠约3.94 mm，而新模型在夹持面处保持约0.012 mm间隙。此对照确认了仿真中夹持槽确实存在。

## 8. 碰撞表示、接触例外及验证边界

- 新构件的封闭表面由实体布尔运算生成，1个连通实体、124个三角面；再用34个凸体精确分区。独立的“减去槽／凹口、加上凸台”模型与分区并集的对称差体积低于1e−5 mm³。
- 每个凸体以独立静态碰撞体载入，由代码保持同一构件位姿，边距明确设为0.05 mm。它们不是动力学装配件，也没有用固定约束假装完成抓取。实际加载器为`component_model.py`；不采用整体凸包。
- 机械臂沿用课程URDF碰撞代理；排除固定连接同组、直接相连刚体组的制造重叠，其余检查自碰撞、地面和其他构件。完整排除对在JSON中。
- 只有两指与中间竖直夹持面可形成预期接触；端部、肩部和凸台不作夹指接触豁免。最终放置时，地面、邻件端面、下层承重／定位面可接近及接触；仍拒绝超过0.11 mm的负距离。该0.11 mm用于容纳两个0.05 mm碰撞皮肤和浮点误差，不是允许CAD实体互相穿透的制造公差。
- 只检查固定基座、水平地面、六个本版构件，没有围栏、桌沿、支架或其他外物。

**步骤3的可达性与给A约束已完成；实际电机跟踪、摩擦夹持、重力下释放落稳、连续路径／插值避碰、材料与惯量、结构强度、雅可比及力矩仍未完成。** 本轮使用关节重设和几何搬运代理，不把它记作真实抓放成功。月面重力不改变这些静态几何结论；月面动力学须后续验证。
