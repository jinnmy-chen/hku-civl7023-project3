## 1. 怎么直接运行

双击项目目录中的[启动位姿控制演示.command](../启动位姿控制演示.command)。演示依次到达取料上方、取料高度、退回上方，再改变夹爪朝向；完成后保留窗口，关闭窗口即可退出。

窗口中深色RGB轴为实际名义TCP，浅色RGB轴为当前目标；X红、Y绿、Z蓝。保存的OpenGL渲染图来自同一图形上下文，不是桌面窗口截图。macOS下已将重绘与控制计算分开，约每仿真秒显示20帧，物理时间步仍为1/240秒。

指定一个自己的目标，例如让夹爪朝下、到达取料位S2上方：

```bash
cd /Users/yhdhhhh/Desktop/7023/05_Project3_月面机器人装配
.venv/bin/python B_基础控制与雅可比/run_pose_control.py \
  --gui --hold \
  --position 0.27 -0.07 0.082 \
  --quaternion 0 1 0 0
```

`--position`为世界坐标下名义TCP的XYZ，单位**米**；`--quaternion`为夹爪目标朝向，顺序**x y z w**。`[0,1,0,0]`对应绕Y转180°、工具朝下。非零四元数会归一化，零四元数、非有限输入、无法找到合格IK解的目标会被拒绝。

默认`auto`会为较大位姿变化加入平滑关节过渡，再用雅可比闭环收敛；`--strategy cartesian`直接使用笛卡尔位姿反馈，适用于已检查过的附近位置。程序有采样碰撞保护，但不是任意场景的完整路径规划器。

不加`--gui`可以无界面运行，仍是真实步进的电机驱动仿真。单目标结果默认保存在`运行验证/基础控制与雅可比/单目标或演示/`，不覆盖29目标验收数据。

## 2. 控制做了什么

1. 解析课程URDF中六个旋转关节、固定变换及TCP偏置，建立正运动学和几何雅可比。
2. 对目标执行有阻尼逆运动学迭代，检查位置／朝向残差和关节边界余量；没有合格解就拒绝，不把被限位截断的关节角冒充成功解。
3. 在单独的无界面模型中预检关节连接、自碰撞和地面间隙。这个检查副本会重设关节；**实际运动模型只在初始化时设置起始姿态，后续均由电机控制和stepSimulation推进**。
4. 大幅运动采用五次多项式关节过渡，再进入雅可比闭环；附近目标可以直接进入闭环。反馈每轮读取实际关节和实际TCP，不依赖理想关节瞬间到位。
5. 连续15个控制周期满足误差和低速条件，才记录“到达”；超时或遇到采样碰撞则退出并保存失败记录。

外环位置和姿态误差均在世界坐标中表达：

```text
e_p = p_target - p_actual
e_R = Log(R_target R_actualᵀ) 的轴角向量
J_i = [ z_i × (p_TCP - o_i) ; z_i ]
[v_TCP ; omega] = J(q) q_dot
```

这里的J为**6×6几何雅可比，前三行线速度、后三行角速度**；后三行不是欧拉角的直接导数。两指开闭关节不会改变本定义下的名义TCP，因此不混入六轴任务雅可比。

外环用`v=3 e_p`、`omega=3 e_R`，再进行任务速度限制。选择特征长度`L=0.3 m`，用`W=diag(I/L,I)`统一平移与转动的相对权重，计算：

```text
J_scaled = W J
velocity_scaled = W [v ; omega]
q_dot = J_scaledᵀ (J_scaled J_scaledᵀ + lambda² I)⁻¹ velocity_scaled
lambda = 0.02
```

关节速率作统一比例限幅，避免改变六轴速度向量的方向。积分生成关节参考，交给PyBullet位置电机执行；参考保留小的稳态补偿量，避免每轮用实际角度覆盖参考而留下重力造成的偏差。另设参考与实测角度的偏差限制，减少积分积累。

| 参数 | 当前值／含义 |
|---|---|
| 物理步长／控制周期 | 1/240 s／1/60 s |
| 重力 | `[0,0,−1.62] m/s²` |
| 基座与负载 | 固定基座，空载；本轮场景没有构件 |
| 外环关节速率上限 | 0.35 rad/s；实际峰值另行记录 |
| 笛卡尔速度上限 | 线速度0.04 m/s、角速度0.3 rad/s |
| 内环位置／速度增益 | 0.15／1；力上限来自URDF effort字段，非已核实硬件能力 |
| IK边界余量 | 各旋转关节距限位至少2° |
| 采样几何保护 | 自身及水平地面2 mm间隙；排除固定连接和相邻关节组的制造重叠 |
| 到达判据 | 位置误差<0.1 mm、姿态误差<0.1°、最大关节速度<0.02 rad/s，连续15周期 |

上述参数和判据是本组空载实验设置，不是教师另行规定的评分标准。

## 3. 如何检查运动学和雅可比

测试60组关节配置，分别使用原点基座和带平移／旋转的基座，各30组；不是只在一个姿态下比较。

| 检查 | 最坏差值 | 说明 |
|---|---:|---|
| 独立URDF正运动学与PyBullet TCP位置 | 约6.79×10⁻¹⁶ m | 双精度数学一致性，不是实际定位精度 |
| 手算几何J与PyBullet J | 约7.78×10⁻¹⁶ | 比较同一TCP、同一世界坐标、同一行顺序 |
| 手算J与PyBullet位姿中央差分 | 约4.85×10⁻¹⁰ | 差分步长1×10⁻⁶ rad，独立检查线／角速度导数 |
| J乘关节速度与PyBullet瞬时速度 | 线速度约1.18×10⁻¹⁶ m/s，角速度约2.92×10⁻¹⁶ rad/s | 核对TCP偏置带来的线速度项 |
| 夹爪两指对应的J列 | 0 | 验证名义TCP不随开口变化 |
| 四元数转换与q／−q等价性 | 22种朝向通过 | 含朝下的180°姿态 |

**坐标陷阱已检查：**getLinkState的COM位姿不能直接当URDF link位姿；本程序先消除惯性变换，再加TCP偏置。使用calculateJacobian时，当前URDF的惯性坐标朝向与link一致，传入本地TCP偏置；固定基座旋转后，另把返回的雅可比转到世界坐标。错误地从TCP偏置减去COM平移的负向对照产生约0.0271的雅可比差值，被检测出来。

零关节位形的加权条件数约14367，但该课程模型有小的几何偏置，数值秩仍是6；不能把它写成已经证实的精确奇异位形。阻尼解在此保持有限。另对一个人工构造的秩5矩阵测试了数值鲁棒性，明确不把它称为机器人实际位形。阻尼不能恢复丢失的运动方向。

数值示例见[雅可比数值示例.json](../运行验证/基础控制与雅可比/雅可比数值示例.json)，取自S2上方的实际测得关节状态。

## 4. 电机驱动定位的实际结果

正式验收包含：槽榫构件V2六个取料位与六个装配位各自的上方／抓放目标24次；1次姿态测试准备动作；1次附近位置调整；3次夹爪朝向变化。合计**29次命名目标定位**，部分角色的上方坐标相同，不能称为29个互不相同的空间点。

| 指标 | 结果 |
|---|---:|
| 到达目标 | **29 / 29** |
| 记录行数／仿真时长 | 3722行／约62.03 s |
| 最差最终位置误差 | **0.045761 mm** |
| 最差最终姿态误差 | **0.044830°** |
| 最小实际关节限位余量 | 约2.293° |
| 实际关节速度峰值 | 约0.2694 rad/s |
| 错误输入拒绝 | 4 / 4，未推进仿真或移动机械臂 |
| GUI复现 | 4次目标全部通过；另测单目标CLI入口通过 |

错误输入为远处无法求解的目标、零四元数、非有限位置和错误位置维数。IK未找到解表示本求解器拒绝执行，不构成全局不可达的数学证明。

后三种朝向测试和附近位置调整均直接使用雅可比闭环，没有先用关节过渡把误差消掉。它们的初始位置误差约8～14 mm，朝向变化测试初始姿态误差约3.44°、6.11°和14.36°，随后收敛到内部门槛内。
