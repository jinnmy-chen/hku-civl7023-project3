# C装配程序的本地入口

整合日期：2026年11月2日。当前工作版本是**16件预置料盘、两层八边形装配**，直接调用本项目已有的B运动学、雅可比与控制模块，以及槽榫构件V2。旧六件直墙几何检查和空载控制结果仍保留各自用途。

## 从这里开始

双击项目目录的[启动C装配演示.command](../启动C装配演示.command)观看GUI。默认完成16件，计算时间可能显著长于仿真时间。每次输出单独保存在`运行验证/C_装配运行/日期时间/`，不会覆盖收到的历史结果。

终端进入`05_Project3_月面机器人装配/`后可运行：

```bash
# 单件完整抓放：其余15件仍在场。
.venv/bin/python C_仿真与装配/run_preloaded_tray_assembly_fast.py --limit 1

# 全16件GUI，并保存本次真实物理运行视频。
.venv/bin/python C_仿真与装配/run_preloaded_tray_assembly_fast.py --gui --video

# 无界面全16件：需要录像时加 --video。
.venv/bin/python C_仿真与装配/run_preloaded_tray_assembly_fast.py

# 根据某次新运行的result和CSV生成汇总表／曲线。
.venv/bin/python C_仿真与装配/summarize_preloaded_tray.py 运行验证/C_装配运行/实际日期时间目录
```

`--limit`接受1至16。`--output`可指定新的输出目录；不要指定收到的`C_装配交付_2026-11-02/最终结果/`。本机依赖已补齐，并同步根项目`requirements.txt`。

## 程序与模型

| 文件／目录 | 用途 |
|---|---|
| run_preloaded_tray_assembly_fast.py | 当前场景、夹爪状态机、接触守卫、16件装配循环与采集入口 |
| gripper_release.py | 有界开爪、实际接触／速度门控、夹指驱动力与接触诊断 |
| preloaded_planning_fast.py | 竖直段采样IK、在线指令检查与DLS反馈 |
| polygon_planning.py、motion_planning.py | 五次关节轨迹、路径检查及RRT-Connect |
| collision_broadphase.py | AABB保守排除，近距离仍作精确查询 |
| preloaded_tray_layout.py、preloaded_tray_scene.py | 16料位、48个取料高度IK检查，以及地面／共面可视化平板 |
| local_paths.py | 定位本地B模块，保留Windows短路径兼容 |
| summarize_preloaded_tray.py | 从真实运行结果生成指标与曲线 |
| ../B_关节与夹爪/、../B_基础控制与雅可比/ | 直接复用本地B代码，无重复handoffs副本 |
| ../B_工作空间与设计约束/构件模型/ | 唯一槽榫V2模型；运行生成单刚体34凸子形状，保留凹槽 |

最初整合调整模块导入、资源／输出路径和源码快照清单，移除未使用的旧方块CollisionWorld。11月2日随后直接修复释放卡滞：接触缓存相对参数0.00001、每物理步4子步、闭爪每指1N，开爪1N并设有最多3N的有界重试；实际开口、清除接触及稳定速度条件保留。详情见[修复说明](../运行验证/C_释放修复_2026-11-02/修复说明与验证.md)。B模块、URDF、构件源模型未改写，RRT算法与碰撞／误差门槛沿用。缓存生成在项目`.cache/C_仿真与装配/`，可重建。
